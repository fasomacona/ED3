3.1 Pilas (Stacks)

Una pila es una estructura lineal con disciplina LIFO (Last In, First Out): el último elemento insertado es el primero en eliminarse. Solo se opera en un extremo, llamado tope (top).

    tope → [ 30 ] ← último en entrar
           [ 20 ]
           [ 10 ] ← fondo
push agrega arriba · pop quita de arriba

3.1.1 Representación en memoria

Con arreglo (estática)

Se reserva un arreglo de capacidad fija y un índice tope.

# Pseudocódigo / idea
capacidad = 100
datos[capacidad]
tope = -1   # pila vacía

# push(x):  tope++; datos[tope] = x
# pop():    x = datos[tope]; tope--; return x
  • Acceso O(1)
  • Riesgo de desbordamiento si se llena
  • No desperdicia punteros por elemento

Con nodos (dinámica)

Cada elemento es un nodo con dato y enlace al siguiente; el tope es la cabeza.

class Nodo:
    def __init__(self, dato):
        self.dato = dato
        self.siguiente = None

# tope apunta al nodo superior
# push: nuevo.siguiente = tope; tope = nuevo
# pop:  x = tope.dato; tope = tope.siguiente
  • Crece según necesidad
  • Sobrecarga de memoria por enlaces
  • Sin límite fijo (salvo memoria del sistema)

3.1.2 Operaciones básicas

Operación Descripción Precondición Complejidad
push(x) Inserta x en el tope Pila no llena (versión estática) O(1)
pop() Elimina y retorna el tope Pila no vacía O(1)
top() / peek() Consulta el tope sin eliminar Pila no vacía O(1)
is_empty() ¿No hay elementos? — O(1)
size() Número de elementos — O(1)*

* Si se mantiene un contador; si no, O(n) recorriendo nodos.

Implementación con lista de Python (dinámica)

class Pila:
    def __init__(self):
        self._datos = []

    def push(self, x):
        self._datos.append(x)

    def pop(self):
        if self.is_empty():
            raise IndexError("Pila vacía")
        return self._datos.pop()

    def top(self):
        if self.is_empty():
            raise IndexError("Pila vacía")
        return self._datos[-1]

    def is_empty(self):
        return len(self._datos) == 0

    def size(self):
        return len(self._datos)

Implementación estática (capacidad fija)

class PilaEstatica:
    def __init__(self, capacidad):
        self._datos = [None] * capacidad
        self._capacidad = capacidad
        self._tope = -1

    def push(self, x):
        if self._tope + 1 >= self._capacidad:
            raise OverflowError("Pila llena")
        self._tope += 1
        self._datos[self._tope] = x

    def pop(self):
        if self.is_empty():
            raise IndexError("Pila vacía")
        x = self._datos[self._tope]
        self._tope -= 1
        return x

    def top(self):
        if self.is_empty():
            raise IndexError("Pila vacía")
        return self._datos[self._tope]

    def is_empty(self):
        return self._tope == -1

    def size(self):
        return self._tope + 1

3.1.3 Aplicaciones

↩️

Historial de navegador / Undo

Cada página visitada (o acción) se apila; “atrás” o “deshacer” hace pop.

📞

Pila de llamadas

El sistema operativo apila marcos de activación al invocar funciones.

🧮

Evaluación de expresiones

Notación postfija / verificación de paréntesis balanceados.

🌳

Recorridos DFS

Profundidad en grafos y árboles (explícita o vía recursión).

Ejemplo: paréntesis balanceados

def balanceados(expr):
    pila = Pila()
    pares = {')': '(', ']': '[', '}': '{'}
    for c in expr:
        if c in '([{':
            pila.push(c)
        elif c in ')]}':
            if pila.is_empty() or pila.pop() != pares[c]:
                return False
    return pila.is_empty()
