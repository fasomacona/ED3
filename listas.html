3.3 Listas enlazadas

Una lista enlazada es una estructura lineal dinámica formada por nodos. Cada nodo contiene un dato y una o más referencias a otros nodos. A diferencia de un arreglo, los elementos no tienen por qué estar contiguos en memoria y el tamaño puede crecer o reducirse fácilmente.

3.3.1 Operaciones básicas

Operación Descripción Simple (típica)
Insertar al inicio Nuevo nodo como cabeza O(1)
Insertar al final Recorrer hasta el último (o usar puntero al final) O(n) / O(1)*
Insertar en posición k Avanzar k−1 nodos y reenlazar O(n)
Eliminar al inicio Avanzar la cabeza O(1)
Eliminar un valor / posición Buscar nodo anterior y reenlazar O(n)
Buscar Recorrer hasta encontrar el valor O(n)
Recorrer / mostrar Visitar todos los nodos O(n)

* O(1) si se mantiene un puntero al último nodo.

3.3.2 Tipos de listas

Lista simplemente enlazada

Cada nodo tiene un enlace al siguiente. Solo se recorre en un sentido.

cabeza → [10|•] → [20|•] → [30|•] → None 
class Nodo:
    def __init__(self, dato):
        self.dato = dato
        self.siguiente = None

class ListaSimple:
    def __init__(self):
        self.cabeza = None

    def insertar_inicio(self, dato):
        nuevo = Nodo(dato)
        nuevo.siguiente = self.cabeza
        self.cabeza = nuevo

    def insertar_final(self, dato):
        nuevo = Nodo(dato)
        if self.cabeza is None:
            self.cabeza = nuevo
            return
        actual = self.cabeza
        while actual.siguiente:
            actual = actual.siguiente
        actual.siguiente = nuevo

    def eliminar(self, dato):
        if self.cabeza is None:
            return False
        if self.cabeza.dato == dato:
            self.cabeza = self.cabeza.siguiente
            return True
        actual = self.cabeza
        while actual.siguiente and actual.siguiente.dato != dato:
            actual = actual.siguiente
        if actual.siguiente:
            actual.siguiente = actual.siguiente.siguiente
            return True
        return False

    def buscar(self, dato):
        actual = self.cabeza
        while actual:
            if actual.dato == dato:
                return True
            actual = actual.siguiente
        return False

    def mostrar(self):
        actual = self.cabeza
        elems = []
        while actual:
            elems.append(str(actual.dato))
            actual = actual.siguiente
        return " → ".join(elems) + " → None"

Lista doblemente enlazada

Cada nodo tiene enlaces al siguiente y al anterior. Se puede recorrer en ambos sentidos. La eliminación es más sencilla si se tiene referencia directa al nodo (no hace falta buscar el predecesor).

None ← [10|•|•] ⇄ [20|•|•] ⇄ [30|•|•] → None 
class NodoDoble:
    def __init__(self, dato):
        self.dato = dato
        self.siguiente = None
        self.anterior = None

class ListaDoble:
    def __init__(self):
        self.cabeza = None
        self.cola = None   # opcional, facilita insertar al final en O(1)

    def insertar_inicio(self, dato):
        nuevo = NodoDoble(dato)
        if self.cabeza is None:
            self.cabeza = self.cola = nuevo
        else:
            nuevo.siguiente = self.cabeza
            self.cabeza.anterior = nuevo
            self.cabeza = nuevo

    def insertar_final(self, dato):
        nuevo = NodoDoble(dato)
        if self.cola is None:
            self.cabeza = self.cola = nuevo
        else:
            self.cola.siguiente = nuevo
            nuevo.anterior = self.cola
            self.cola = nuevo

    def eliminar(self, dato):
        actual = self.cabeza
        while actual and actual.dato != dato:
            actual = actual.siguiente
        if actual is None:
            return False
        if actual.anterior:
            actual.anterior.siguiente = actual.siguiente
        else:
            self.cabeza = actual.siguiente
        if actual.siguiente:
            actual.siguiente.anterior = actual.anterior
        else:
            self.cola = actual.anterior
        return True

Lista circular

El último nodo apunta de nuevo al primero (en la simple) o se forma un anillo (en la doble). No hay None de terminación; se detecta el fin al volver a la cabeza.

cabeza → [A|•] → [B|•] → [C|•] ─┐
          ↑__________________┘

Aplicaciones: round-robin, playlists en bucle, buffers circulares.

class ListaCircular:
    def __init__(self):
        self.cabeza = None

    def insertar_final(self, dato):
        nuevo = Nodo(dato)
        if self.cabeza is None:
            self.cabeza = nuevo
            nuevo.siguiente = nuevo  # apunta a sí mismo
            return
        actual = self.cabeza
        while actual.siguiente != self.cabeza:
            actual = actual.siguiente
        actual.siguiente = nuevo
        nuevo.siguiente = self.cabeza

    def mostrar(self, max_vueltas=1):
        if self.cabeza is None:
            return "vacía"
        elems = []
        actual = self.cabeza
        for _ in range(max_vueltas):
            while True:
                elems.append(str(actual.dato))
                actual = actual.siguiente
                if actual == self.cabeza:
                    break
        return " → ".join(elems) + " → (circular)"

A Comparación: arreglo vs lista enlazada

Aspecto Arreglo / vector Lista enlazada
Acceso por índice O(1) O(n)
Inserción al inicio O(n) O(1)
Inserción al final O(1)* O(1)**
Memoria extra Baja (bloque contiguo) Alta (punteros por nodo)
Localidad de caché Excelente Pobre (nodos dispersos)
Tamaño Fijo o redimensionable Dinámico naturalmente

* Amortizado en vectores dinámicos. ** Con puntero al final.

3.3.3 Aplicaciones

📋

Listas de tareas / historiales

Inserción y eliminación frecuente en posiciones variables.

🎵

Playlists y buffers

Listas circulares para reproducción en bucle.

🧩

Base de otras estructuras

Pilas, colas, grafos (listas de adyacencia), hash chaining.

↩️

Editores y navegación

Listas dobles para avanzar/retroceder (undo-redo, pestañas).

📝 Actividades del programa Utilizar clases predefinidas y/o implementar listas enlazadas; aplicarlas en la resolución de problemas y elaborar reportes de práctica.
