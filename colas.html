3.2 Colas (Queues)

Una cola es una estructura lineal con disciplina FIFO (First In, First Out): el primer elemento en entrar es el primero en salir. Se inserta por el final (rear) y se elimina por el frente (front).

frente → [ A ] [ B ] [ C ] [ D ] ← final
dequeue quita A · enqueue agrega después de D

3.2.1 Representación en memoria

Con arreglo

Se usan índices frente y final. Si no se reutiliza el espacio, el arreglo se “desgasta” hacia un lado (por eso existen las colas circulares).

Con nodos enlazados

Se mantienen punteros al frente y al final. enqueue enlaza al final; dequeue avanza el frente. Ambas operaciones en O(1).

3.2.2 Operaciones básicas

Operación Descripción Complejidad típica
enqueue(x) / put(x) Inserta x al final O(1)
dequeue() / get() Elimina y retorna el frente O(1)*
front() / peek() Consulta el frente O(1)
is_empty() ¿Vacía? O(1)
size() Número de elementos O(1)

* Con lista de Python, pop(0) es O(n); por eso se prefiere collections.deque o una implementación con nodos / índices circulares.

Implementación con collections.deque (recomendada en Python)

from collections import deque

class Cola:
    def __init__(self):
        self._datos = deque()

    def enqueue(self, x):
        self._datos.append(x)

    def dequeue(self):
        if self.is_empty():
            raise IndexError("Cola vacía")
        return self._datos.popleft()

    def front(self):
        if self.is_empty():
            raise IndexError("Cola vacía")
        return self._datos[0]

    def is_empty(self):
        return len(self._datos) == 0

    def size(self):
        return len(self._datos)

3.2.3 Tipos de colas

Cola simple

FIFO clásica: un solo frente y un solo final. Las operaciones solo se realizan en esos extremos.

Cola circular

El arreglo se trata como circular: al llegar al final se vuelve al inicio. Así se reutiliza el espacio liberado por los dequeue. 

class ColaCircular:
    def __init__(self, capacidad):
        self._datos = [None] * capacidad
        self._cap = capacidad
        self._frente = 0
        self._final = 0
        self._n = 0

    def enqueue(self, x):
        if self._n == self._cap:
            raise OverflowError("Cola llena")
        self._datos[self._final] = x
        self._final = (self._final + 1) % self._cap
        self._n += 1

    def dequeue(self):
        if self._n == 0:
            raise IndexError("Cola vacía")
        x = self._datos[self._frente]
        self._frente = (self._frente + 1) % self._cap
        self._n -= 1
        return x

    def is_empty(self):
        return self._n == 0

    def size(self):
        return self._n
Índices: 0 1 2 3 4
Datos: [ ][B][C][D][ ] frente=1, final=4, n=3
Tras más operaciones el “hueco” se reutiliza

Bicola (Deque — Double-Ended Queue)

Permite inserción y eliminación en ambos extremos. Útil cuando se necesita flexibilidad de pila y cola a la vez.

OperaciónDescripción
push_front(x) / push_back(x)Insertar al frente o al final
pop_front() / pop_back()Eliminar del frente o del final

En Python: collections.deque ya ofrece appendleft, popleft, append, pop.

Cola de prioridad

Cada elemento tiene una prioridad. Sale primero el de mayor (o menor) prioridad, no necesariamente el que llegó antes. Se implementa a menudo con heaps (montículos) → O(log n) por operación. 

import heapq

class ColaPrioridad:
    def __init__(self):
        self._heap = []   # min-heap: menor número = mayor prioridad
        self._contador = 0

    def enqueue(self, item, prioridad):
        # contador evita comparar items si hay empate de prioridad
        heapq.heappush(self._heap, (prioridad, self._contador, item))
        self._contador += 1

    def dequeue(self):
        if not self._heap:
            raise IndexError("Cola vacía")
        return heapq.heappop(self._heap)[2]

    def is_empty(self):
        return len(self._heap) == 0

3.2.4 Aplicaciones

🖨️

Colas de impresión / atención

Documentos o clientes se atienden en el orden de llegada.

✈️

Simulación de aeropuertos

Despegue/aterrizaje; con prioridad para emergencias.

🖥️

Planificación de procesos

CPU scheduling (Round-Robin usa cola circular).

🔍

BFS en grafos

Recorrido en anchura: se encolan los vecinos por niveles.

📝 Actividades del programa Programar colas estáticas y dinámicas; simular lista de espera de mesas en un restaurante y salida de aviones con colas de prioridad.
